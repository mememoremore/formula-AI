# 业务接口与后续接入协议

所有路径与页面同源。`shared/types/api.ts` 定义访客模拟协议，`account.ts` 定义账号协议，`workspace.ts` 定义真实上传、保存和历史协议。识别内容与对话回答仍为模拟；账号图片、结果、版本和历史使用真实存储与数据库。后台队列、额度、账号对话和 Word 已接入，协议见下方第8至9天部分。

## 第8至9天：后台任务、账号对话和 Word

本节是当前账号业务协议。所有接口均校验会话；写操作另校验本站 Origin。身份只取自会话，资源必须属于本人。JSON 请求体最多32KB，私有响应禁止缓存。

| 接口                                           | 输入                                                        | 返回                                              |
| ---------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------- |
| `POST /api/account/recognitions`               | `{ fileId, mode, requestKey }`，mode 为 handwritten/printed | HTTP202，`RecognitionTaskState`                   |
| `GET /api/account/tasks/:id`                   | 本人识别任务 ID                                             | `RecognitionTaskState`                            |
| `GET /api/account/versions/:id`                | 本人公式版本 ID                                             | `{ id, formulaId, title, number, latex }`         |
| `POST /api/account/conversations`              | `{ formulaVersionId: UUID或null, requestKey }`              | `SavedConversation`                               |
| `GET /api/account/conversations`               | 可选本人 cursor                                             | `{ items, nextCursor }`，每页20条                 |
| `GET /api/account/conversations/:id`           | 本人对话 ID                                                 | `SavedConversation`，最近100条消息及当前轮次      |
| `POST /api/account/conversations/:id/messages` | `{ question, requestKey }`，question 最多2000字符           | HTTP202，`TaskState`                              |
| `POST /api/account/exports`                    | `{ formulaVersionId, requestKey }`                          | HTTP202，`ExportTaskState`                        |
| `GET /api/account/exports/:id`                 | 本人导出任务 ID                                             | `ExportTaskState`                                 |
| `GET /api/account/exports/:id/download`        | 本人已完成任务 ID                                           | DOCX 附件，不返回存储路径                         |
| `GET /api/account/usage`                       | 无                                                          | UTC 日期、下次重置时间、三类 used/limit/remaining |

任务公共字段为 `id`、`status`、`attemptCount`、`maxAttempts`、`errorMessage`。状态使用大写 `QUEUED / PROCESSING / COMPLETED / FAILED`。识别任务另有 `fileId`、`mode`、可空 `formulaId` 和 `isMock`；导出任务另有标题、公式版本 ID、版本号及可空 `downloadUrl`。

提交被接受不等于处理完成。前端查询任务状态，完成后再打开公式或下载文件。当前页面每1.5秒轮询，终态、离开页面或读取失败时停止；失败后可手动重新读取。

`requestKey` 为客户端生成的 UUID，在用户范围内唯一。同一业务接口重放同一编号返回已有任务，不重复扣额；改变图片/模式、问题或版本会409。创建任务、额度与入队同事务，失败全部回滚。主动重新提交失败任务需新编号，并使用一次新额度。

同一对话有排队/处理中轮次时，新问题返回409。客户端只提供问题和服务器可验证的版本标识，不提供可信 LaTeX、系统角色或历史消息。Worker 从数据库组装上下文。流式回答仍未实现。

未登录401，他人或不存在资源404，参数错误400，来源错误403，额度不足429，资源/请求冲突409。未生成成功的文件下载409；任务服务初始化失败503。识别与回答仍为模拟，Word 是真实可编辑文档。

完整字段见 [tasks.ts](../shared/types/tasks.ts)，处理策略见 [第8至9天开发说明](第8至9天开发说明.md)。

## 第7天：公式库、分类和收藏

以下接口全部需要有效会话，身份只取自服务器会话；写操作还校验本站 Origin。未登录401，他人资源或不存在资源404，无效参数400，重名或并发冲突409。请求体继续限制32KB。类型定义见 [library.ts](../shared/types/library.ts)。

| 接口                                     | 参数                                        | 返回                                                                      |
| ---------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------- |
| `GET /api/account/library`               | 可选 `q`、`category`、`favorites`、`cursor` | `{ items, nextCursor }`                                                   |
| `GET /api/account/categories`            | 无                                          | `{ items: [{ id, name, formulaCount }], totalCount, uncategorizedCount }` |
| `POST /api/account/categories`           | `{ name }`                                  | `{ id, name, formulaCount: 0 }`                                           |
| `PATCH /api/account/categories/:id`      | `{ name }`                                  | `{ id, name }`                                                            |
| `DELETE /api/account/categories/:id`     | 无请求体                                    | `{ deleted: true }`，保留公式、版本和收藏                                 |
| `PUT /api/account/formulas/:id/category` | `{ categoryId: UUID或null }`                | 完整 `SavedFormula`                                                       |
| `PUT /api/account/formulas/:id/favorite` | `{ favorite: true或false }`                 | `{ favorite }`，重复请求不会反转状态                                      |

`q` 最多200字符，去首尾空格、忽略大小写，按普通文本匹配标题和最新版本 LaTeX；不搜索旧版本。`category` 为本人分类 UUID 或 `uncategorized`，不传即全部分类；`favorites` 仅接受字符串 `true` 或 `false`。`cursor` 为本人公式 UUID，排序依据是创建时间和 ID 倒序，每页20条；不能传他人的游标，也不能通过 ownerId 查询他人。

```text
GET /api/account/library?q=积分&category=uncategorized&favorites=true
```

列表项包含 `id`、`title`、`createdAt`、`latex`、`versionNumber`、`isMock`、`category: { id, name } | null`、`favorite`。详情 `SavedFormula` 也新增 `category`、`favorite`，原上传、版本和历史接口保持兼容。

分类名称去首尾空格、Unicode NFC 规范化，1～50字符，不接受换行和控制字符，同一用户按名称精确去重。分类统计覆盖本人全部公式，与当前列表的搜索和收藏筛选独立。

## 第5至6天：真实上传与保存

这些接口均需要会话；写入还需匹配本站的 Origin。请求中的 ownerId 不作为身份依据。未登录 401，外部或不存在资源 404，格式错误 400/415，超限 413，请求或版本冲突 409，存储暂时失败 503。

| 方法与路径                                | 请求                                                                                                          | 成功响应                                             |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `POST /api/account/files`                 | JPEG/PNG 原始二进制；Content-Type 为真实 MIME，X-File-Name 为 encodeURIComponent 文件名，X-Upload-Key 为 UUID | `{image: {id,name,mimeType,sizeBytes,width,height}}` |
| `GET /api/account/files/:id/content`      | 浏览器携带 Cookie                                                                                             | 经过归属检查的图片字节，不缓存                       |
| `POST /api/account/recognitions`          | `{fileId, mode: "handwritten"或"printed", requestKey: UUID}`                                                  | `HTTP202任务状态，见第8至9天协议`                    |
| `GET /api/account/formulas/:id`           | 公式 UUID                                                                                                     | SavedFormula：名称、图片展示元数据、版本列表及时间   |
| `POST /api/account/formulas/:id/versions` | `{title,latex,expectedVersionId,expectedTitle}`                                                               | 更新后的 SavedFormula                                |
| `GET /api/account/formulas?cursor=UUID`   | cursor 可省略                                                                                                 | `{items,nextCursor}`，每页最多 20 条                 |

上传限制按实际字节执行，包含没有 Content-Length 的请求。真实文件格式与声明 MIME 必须匹配；完整解码后最多 2000 万像素，自动校正方向并移除元数据。sizeBytes 是规范化后实际存储的大小。

请求键在用户内唯一。同上传请求键的图片内容、名称或 MIME 变化会返回 409；仍在进行中的上传也返回 409。识别请求键不能换文件或模式，重放已完成请求返回已有结果。客户端重试沿用请求键，重新选图或更换模式时创建相应新键。

保存要求提交打开编辑时看到的版本 ID 和原标题 expectedTitle（原样传回，不用新标题代替）。服务端在同一 Serializable 事务中校验两者，任一过期返回 409。缺失或非法 expectedTitle 返回 400，提示刷新页面后重新编辑；没有不受保护的旧请求兼容路径。第一版不可覆盖，相同内容或仅改名称不新增版本。所有写入 JSON 限 32KB，LaTeX 最多 5000 字，名称最多 100 字。

版本保存没有 requestKey：已改变状态的请求重放返回 409，不再写入；标题与内容均未改变的请求可重复返回 200。超时结果不确定时先读取当前公式，不能自动重放旧草稿。其他上传、任务接口的请求键规则不变。

图片响应和 DTO 不包含 bucket、objectKey、存储 URL 或私有凭据。Day8起通过队列调用固定模拟适配器，仍没有真实模型或置信度。

详见 [第5至6天开发说明](第5至6天开发说明.md)。

## Day 4：真实认证与私有账号接口

| 方法与路径                             | 内容                                                     | 访问条件                           |
| -------------------------------------- | -------------------------------------------------------- | ---------------------------------- |
| `POST /api/auth/sign-up/email`         | `{name, email, password}` 创建账号并登录                 | 来源校验、昵称与密码检查、注册限流 |
| `POST /api/auth/sign-in/email`         | `{email, password}` 登录                                 | 来源校验、密码验证、登录限流       |
| `POST /api/auth/sign-out`              | 撤销当前会话、清 Cookie                                  | 当前 Cookie、来源校验              |
| `GET /api/account/session`             | `{user: {id,name,email,emailVerified}}` 或 `{user:null}` | 不返回令牌，不缓存                 |
| `GET /api/account/overview`            | 当前用户的四类资源计数及最近十条公式标题                 | 必须有数据库有效会话               |
| `GET /api/account/resources/:kind/:id` | `{resource: 展示字段}`                                   | 必须登录且属于当前用户             |

资源 kind 为 `formulas`、`versions`、`files`、`tasks`、`categories`、`conversations`。私有 API 不接收可信 ownerId；从会话确定身份。未登录 401，外部与不存在资源统一 404。文件响应不含存储路径，对话消息最多返回前 100 条。所有账号响应禁止缓存。

密码至少 10、最多 128 字符。注册返回的用户邮箱未验证；没有配置邮箱验证与找回密码。身份由 HttpOnly Cookie 维持，页面不保存登录令牌。更多认证端点由 Better Auth 提供，但只启用已配置的功能；本次产品界面只使用注册、登录、会话和退出。

实现与安全策略见 [第4天开发说明](第4天开发说明.md)。

## 保留的访客模拟接口

### GET /api/health

返回 `status: "ok"`、应用名称、`recognition: "mock"`、`chat: "mock"` 与 `persistence: "browser-demo"`。首页实际请求此接口，显示连接或失败状态。响应不返回环境变量、密钥或内部服务地址。

### GET /api/formulas

返回 `{ items: Formula[], categories: Category[], isMock: true }`，用于固定示例列表协议。当前用户在页面上的修改保存于本机，不会写回此端点。

### POST /api/recognitions

请求示例：

```json
{
  "image": { "name": "formula.png", "mimeType": "image/png", "size": 2048 },
  "mode": "handwritten"
}
```

`mode` 只接受 `handwritten`、`printed`；名称 1～255 字；类型为 JPEG/PNG；大小为正整数且不超过 10MB。这个访客端点不接受真实文件流，只检查元信息；正式上传已由上面的账号接口完整解码检查。

```json
{
  "requestId": "服务端生成的 UUID",
  "latex": "x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}",
  "modelVersion": "mock-v1",
  "isMock": true
}
```

固定结果不会根据图片或识别模式变化。`confidence` 是可选字段，当前不返回，也不在 UI 展示伪造百分比。`requestId` 标识本次调用，当前没有持久化后台任务。

### POST /api/chat

```json
{
  "formula": { "versionId": "energy-v1", "latex": "E = mc^2" },
  "messages": [{ "role": "user", "content": "这个公式是什么意思？" }]
}
```

`formula` 可省略，表示普通对话。`versionId` 最长 100 字，LaTeX 最长 5000 字；消息 1～20 条，角色只接受 `user`/`assistant`，内容 1～2000 字，末条必须为用户提问。

响应为 `ChatResponse`：`requestId`、`message`、`formulaVersionId`、`isMock: true`。回答为固定说明文本，不进行推理。前端按版本分别保存最近 10 轮对话；网络失败会回滚未完成的消息并保留输入，便于重试。

当前 API **信任的是经过格式检查的演示上下文**，不验证数据库资源归属。正式接入必须只接受服务器可验证的公式版本标识，从数据库读取该用户拥有的 LaTeX，不能直接信任浏览器提交的公式内容。

### 错误

格式无效的请求返回 HTTP 400，JSON 包含 `message`。前端显示错误并允许重试；不把失败伪装成成功。框架生成的错误字段（如 `statusCode`）由 Nitro 管理。

## 识别协议的演进

当前账号先上传图片至私有存储并取得属于当前用户的 `fileId`，再提交后台任务。真实队列和状态查询已经完成，账号协议使用 `QUEUED | PROCESSING | COMPLETED | FAILED`。首日的小写 `TaskStatus` 和模拟接口保留用于访客协议，不混用两者。

前端继续消费统一 `RecognitionResult`；Python 返回格式、预处理、模型版本等由服务端真实适配器转换，朋友不必直接实现产品业务协议或连接 pg-boss。

第11天拟议的内部 Python HTTP 协议、材料与错误映射见 [Python模型接入交接清单](Python模型接入交接清单.md)。它与已实现的浏览器业务 API 分开，当前尚未接通真实 Python 服务。

## 账号 AI 流式协议

已实现 `GET /api/account/conversations/:id/events`，只读取本人持久化对话，不创建模型调用或扣额：

1. `event: snapshot`：`data`为 `SavedConversation`，当前轮次附`partialContent`、`isMock`、`modelVersion`。
2. 约750ms读取一次，变化时才发快照；终态后关闭，连接最多约60秒。会话和资源归属持续复查。
3. `event: stream-error`：`data`为`{ code: 401 | 503 }`，不暴露原始错误；前端关闭SSE并退回有鉴权的轮询。

`POST /api/account/conversations/:id/turns/:turnId/cancel`要求本人会话和有效Origin，停止任务并保存未完成片段，返回最新对话；重复停止不重复建消息。`GET /api/account/chat-settings`只返回当前类型、模型名和是否就绪，不返回地址或密钥。缺密钥的真实模式提交问题返回503且不扣额。当前实际协议替代首日预留的start/delta/done草案。配置见 [DeepSeek配置与联调手册](DeepSeek配置与联调手册.md)。

## 密钥边界

`NUXT_DATABASE_URL`、`NUXT_RECOGNITION_SERVICE_URL`、`NUXT_RECOGNITION_API_KEY`、`NUXT_AI_API_KEY` 对应私有 `runtimeConfig` 字段。Vue 页面只请求同源 API，不直接连接 Python、数据库或大模型。任何密钥均不能放入 `runtimeConfig.public`。
