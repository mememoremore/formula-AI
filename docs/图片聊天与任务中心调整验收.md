# 图片聊天、批量清单与任务中心调整验收（2026-11-09）

## 最终行为

1. 账号聊天支持选择或粘贴 JPG/JPEG、PNG 公式图片，每张不超过10MB；先预览，点击“识别并插入”才上传和识别。可以选择手写或印刷。每张识别1条公式、使用1次识别额度；聊天发送按原AI额度规则执行。
2. 输入区域保留原图，显示排版后的公式预览；文本输入保留可修改的公式源码与问题。发出后原图与公式继续显示，刷新对话可以恢复。数学公式及单个数学变量使用现有安全排版组件展示。
3. 每条消息最多插入3张公式图片，沿用原2000字提问总长度限制；私有图片引用也计入长度。不保存尚未发送的图片文件到浏览器持久化存储；已提交后台识别任务仍可在任务中心查看。
4. 识别提交、上传未知响应重试沿用原请求编号；读取已有任务不会新建一次识别，超长提问缩短后复用已识别结果。账号或页面变化会停止前端等待，不中断已提交后台任务。
5. “生成学习清单”位于全选、删除同一操作行；删除“学习单每次最多选择20条公式。”提示；导出原有20条上限保持有效。
6. 任务中心只显示创建时间最新20条任务；只看待处理筛选在这20条内进行。更早记录只隐藏，不删除，不停止任务；待处理摘要仍统计全部后台任务。

## 实现与兼容

复用原图片上传、识别队列和聊天发送接口，不改数据库结构或API字段。图片使用账号私有文件地址，消息仍保留兼容的文字内容；显示层仅识别固定格式的私有图片标记，普通HTML与外部图片不会被当作可信附件。模型是文字接口，实际收到识别或用户校对的公式，不会被误称为直接读取原图。
