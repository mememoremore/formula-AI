# AI 解释公式渲染修复

**Goal:** 新解释中的数学格式可校验，旧解释中明确的裸 LaTeX 可安全显示；不改历史原文。
**Architecture:** 共用有界分段器，先保护代码和显式数学标记，再保守识别裸公式。decodeExplanation 仅对新生成结果规范化并校验；parseExplanation 保持旧记录兼容。
**Tech Stack:** Vue 3、TypeScript、现有 KaTeX；无新依赖、无数据库变更。
**Spec:** 用户在本轮确认的三项方案：规范新回答、兼容旧回答、长公式独立滚动。

- [x] 在 shared/math-content.ts 提取分段与规范化；app/utils/chat-content.ts 保留原导出契约。代码、英文、文件路径、未闭合公式不得猜测成数学。
- [x] 增强结构化提示词；decodeExplanation 对文本字段规范化并校验数学片段；不更改 parseExplanation 与历史存储。
- [x] 长公式独立成行，保持公式局部滚动；检查 symbols.meaning 也使用富数学展示。
- [x] tests/chat-content.test.ts 覆盖截图两个例子、已定界公式、代码、货币、路径、错误/流式公式和保守回退；tests/explanation.test.ts 覆盖新输出规范化与旧数据不变。
- [x] 隔离 E2E 注入受控旧解释样本，320/390/430px 验证 KaTeX 与无页面横溢；运行 quality:quick。

不自动重调模型、不耗真实额度、不执行迁移、不提交 Git，完成后报告验证结果及兼容范围。
