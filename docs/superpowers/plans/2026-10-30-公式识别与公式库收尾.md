# 公式识别与公式库收尾实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成识别前命名、公式安全删除、即时旋转和相关 UI 收尾，同时保留历史会话、导出与资源生命周期语义。

**Architecture:** 使用两个向后兼容的可空字段记录识别名称与公式删除时间。API 负责校验和 HTTP 语义，数据库函数负责幂等事务与软删除，Worker 只消费任务中已持久化的名称；前端继续使用现有 Composables 和设计组件。

**Tech Stack:** Nuxt 4、Vue 3、TypeScript、Prisma 7、PostgreSQL、pg-boss、Cropper.js 2.3.1、Playwright。

**Spec:** `docs/superpowers/specs/2026-10-30-公式识别与公式库收尾设计.md`

## Global Constraints

- 不改变识别额度、Worker 执行权、任务终态和对象存储清理语义。
- 不删除历史公式版本、AI 会话、解释、导出任务或文件。
- 数据库迁移仅在 R1 隔离环境执行验证。
- 所有新增 API 继续执行账号归属校验和请求幂等保护。
- 不调用真实付费模型。
