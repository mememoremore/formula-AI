# R10 全站17页、错误页与弹窗验收矩阵

基线：实际 `app/pages` 共17个Vue文件。测试预览层 `__*` 页面不是正式产品路由，不计入17页。旧 `/account/*`、`/favorites`、`/history` 兼容跳转保留。

## 覆盖口径

- `手机✓`：320、390、430px逐页真实浏览器截图、脚本/水合诊断、图片加载、横向溢出检查。
- `桌面✓`：1440px同样逐页检查。R10四页和错误页另测768/1024px；其余页面平板/桌面补充覆盖来自本轮重跑的R3—R9专项脚本，没有虚称每页在每个宽度跑过所有业务状态。
- `导航✓`：本轮390px逐页直接打开、刷新、SPA跳往关于/帮助后浏览器后退，并核对原路径、查询及页面标题。实际业务返回/旧地址/滚动另见专项脚本，不能把通用返回烟测当成所有跳转组合。
- `底部✓`：有底栏页面实际滚动到底，末尾内容位于导航上方，另存底部截图。无底栏页面维持原规则。
- 下面“状态”列描述**专项脚本实际覆盖**；17页矩阵主循环主要是成功态/可操作态。加载态用受控延迟，失败/断线/剪贴板用Mock；真实DB/对象存储/Worker断言来自106项隔离集成，详见交付说明。
- 不把真实桌面浏览器改视口称为手机实体设备验收。

## 全局错误与全站弹窗

`app/error.vue`单独验收，不计入17个路由文件：404六宽度、503恢复、可信返回与首页、权限通用提示；不渲染原始message/stack，不依赖Session。身份中间件读取失败会直接进入503全局错误，而非伪造游客成功页。

13处AppModal调用点及各自的业务状态覆盖见 [交付说明](R10全站收尾与验收说明.md#弹窗与导航)。R10补验四类游客弹窗×四宽度，并重跑R3公共层级、R5分类管理、R6编辑/版本/导出、R8选择器和R9头像/清理。没有为了列表完整而新增收藏/退出确认。

## 剩余验收边界

所有截图和Mock状态验证通过仍不代表实体手机软键盘、iOS Safari、屏幕阅读器、真实模型质量、生产CDN或压力性能已验证。更早消息分页、可靠SSE revision、Worker异常收敛、累计上传容量、存储回收分别进入R11—R17，不由本轮UI验收关闭。

本轮没有删除、隐藏或减少正式页面。第一阶段UI交付等待人工视觉评审；R10结束后不自动进入R11。
