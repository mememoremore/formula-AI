# 公式卡片点击范围与仅新公式推荐调整

日期：2026-11-10

## 最终行为

1. 公式库卡片除分类标签、爱心外，空白、公式等区域点击均进入对应详情；已有标题链接保留。滑动公式或选中文字时不误跳，公式获得焦点后可按Enter进入详情。
2. 移除“尚未掌握，建议先理解符号含义和适用条件。”以及卡片底部“生成个性化推荐”入口。
3. 推荐接口不再返回库内规则预览；生成失败、缓存无效或旧缓存包含库内公式时只返回空列表和状态，不回退库内内容。浏览器也过滤旧式库内条目。
4. 仅展示连续推导、结构相似、含义相近、化简等新公式，来源仍须来自本人公式库；来源、条件和推导核对信息保留。
5. 新公式去重检查扩展到当前账号整个未删除公式库的最新版本，不限于送给AI的20条候选；缓存读取时也重查，避免保存后继续推荐同一公式。当前采用保守的LaTeX空白规范化比较，允许化简和等价变形产生不同形式，不声称已经证明数学等价。
6. 没有生成结果时，用户点击右上角“换一个”触发生成或重试；打开页面不自动扣AI额度。已有多条生成结果时“换一个”只切换缓存；只有一条时禁用空轮换。
7. 推荐缓存指纹版本升级，旧库内推荐不作为本次结果复用；未修改数据库结构或清除用户数据。

## 文件及原因

- app/components/FormulaListCard.vue：扩大点击范围，保留按钮、链接、横向滑动和文本选择行为。
- app/components/PersonalizedRecommendations.vue：移除旧库内卡片与底部生成入口；换一个承载显式首次生成，保留空状态。
- server/database/recommendations.ts：取消库内回退，校验完整公式库、拒绝旧缓存、升级指纹。
- shared/recommendations.ts：支持传入完整公式库进行去重，候选仍用于来源核验。
- tests/components/formula-card-navigation.test.ts：点击区域、按钮独立操作、滑动与键盘测试。
- tests/components/personalized-recommendations.test.ts：只显示新公式、无底部入口、显式生成、失败重试与缓存切换。
- tests/recommendations.test.ts：库外候选集重复拦截、旧缓存排除及失败不回退检查。
