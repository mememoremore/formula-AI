# 005：私有对象、写入租约与受限回收

状态：当前采用。

## 背景

数据库与对象存储无法共享一个事务。对象写入成功后进程退出，或删除完成但响应丢失，都会留下不确定状态。按年龄删文件可能误删有效输入。

## 决策

对象存储保持私有，账号 API 校验访问。数据库记录 StoredFile、ResourceLease 和清理审计。外部 I/O 不持有长事务锁；关键状态变更时在锁内复查引用与执行条件。

孤立图片核对默认 report，显式 apply 只处理登记完成、无引用、无活动或不确定租约、超过至少 24 小时宽限期的 IMAGE。删除后确认对象缺失才落账。未知对象、PENDING、头像、DOCX、模型与备份不进入此范围。

## 替代方案与代价

公开桶直连降低代理成本，但不符合当前账号私有需求。数据库直接保存大文件简化部分一致性，却扩大备份和数据库负担。当前方案承担租约、审计、恢复状态机与数据库/存储联合备份成本。

SeaweedFS 是当前本地与单机 S3 兼容实现；业务通过对象存储接口访问，后续迁移需要验证签名、错误语义和恢复规则，不能仅替换 URL。

## 实现与验证

[资源模块](../../server/resources)、[存储适配器](../../server/storage/object-store.ts)、[失败恢复](../FAILURE_RECOVERY.md)。验证包括引用竞争、写入不明、删除响应丢失和重复核对；禁止全桶清理代替这些规则。
