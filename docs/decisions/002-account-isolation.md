# 002：服务端会话决定账号归属

状态：当前采用。

## 背景

同一浏览器可退出后登录另一账号，异步请求和缓存可能晚到。只在页面过滤 owner 无法保护私有公式、图片和任务。

## 决策

Better Auth 会话是服务端身份来源。读写查询限定 owner，资源关系使用必要的复合外键和唯一约束；写请求检查 Origin/CSRF。资源不属于当前账号时不暴露存在性。前端 owner 范围键、账号错配头与缓存清理提供额外一致性保护，不作为授权。

## 替代方案与代价

信任客户端 ownerId 简单但不安全；仅靠缓存 key 无法阻止直接 HTTP 越权。本项目未启用数据库 RLS，所有服务查询和事务必须持续维护归属条件，并以跨账号测试保护。

旧演示代码保留兼容，但产品入口要求登录，不能以“只是本机演示”为由绕过正式账号路径。
