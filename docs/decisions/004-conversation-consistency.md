# 004：数据库快照与内部公式内容绑定

状态：当前采用。

## 背景

SSE、停止响应和轮询可能乱序。若解释直接跟随一份可变公式，用户编辑后旧回答会看起来对应新的内容。

## 决策

会话和轮次进度持久化，SSE 推送快照，前端按会话和版本判断新旧；刷新或断线通过只读接口恢复。保留已收到的失败片段，完整成功问答才进入后续上下文。

公式编辑保存不可变 FormulaVersion，现有会话和导出绑定当时内容。产品去掉 v1/v2 标签和版本选择操作，后台内容绑定仍用于历史一致性。编辑带预期内容与标题，拒绝覆盖别处修改。

## 替代方案与代价

只把 token 存在浏览器实现更少，但无法可靠刷新恢复或解决多终端状态。直接覆盖历史内容节约数据，却改变旧回答的上下文。当前选择增加存储与版本判断代码；这不是向用户推出版本管理功能。

重新生成是新轮次和新额度，不是恢复供应商计算状态；未知外部调用结果保留审计。
