# 登录表单自动填充修复（2026-11-08）

现象：用户截图显示“邮箱或密码不正确”。已确认截图账号与之前QQ账号均存在、已验证且密码凭据有效。未重置密码，未改账号信息。

排查与复现：两组已提供凭据手动填写均返回200，建立会话并跳转首页。模拟密码管理器只更改DOM显示值、没有触发input事件时，旧实现提交Vue中旧密码，返回401；请求密码与输入框当前值不一致。本轮确认了这一可导致同类现象的缺陷，不声称已取得用户原浏览器失败请求的具体内容。

修改：app/pages/login.vue。提交时在禁用字段前读取当前表单FormData，补充邮箱、密码、昵称的标准name属性。保留原有邮箱规范化、密码原样传递、注册验证、来源校验、限流和会话确认逻辑。无新增依赖，无数据库或账号设置变更。

验证：同一自动填充替身场景修复后返回200，请求内容与显示值一致，会话建立并跳转首页，页面脚本错误0。常规手动登录两组账号均成功。所有浏览器验证使用独立会话，完成后退出该验证会话，没有替换用户原浏览器的登录状态。检查脚本从临时标准输入接收已提供凭据，不把密码或散列写入文件或输出。

已执行Prettier与该页面ESLint，均通过。页面类型检查与构建结果在完成后补记。
