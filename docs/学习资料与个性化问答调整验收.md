# 学习资料与个性化问答调整验收

日期：2026-11-09；本说明记录本轮调整，入口与按钮以本说明及当前代码为准。

## 已实现的八项调整

1. 任务页“刷新状态”放在筛选行右端，与任务卡片状态的右边界对齐；手机和桌面均不超出。
2. 仅保留“我的”页面的任务中心入口；删除全局顶部入口组件，恢复页面原有顶部间距，并停止对应的全局数量轮询。
3. 学习清单标题与输入框之间增加10px间距，相关按钮统一使用“学习清单”名称。
4. 学习笔记底部只保留“保存学习笔记”“生成学习清单”，在同一行显示；移除“重新读取”“开始复习”两个操作。生成清单会先保存当前笔记，保证新输入内容进入导出结果；保存失败时不会继续导出。
5. 编辑资料增加可选填的“年级”“学习目的”，允许留空和清空；通过原资料接口保存，并在账号会话中同步。
6. 按本轮确认，为每条公式保存“不熟悉／已掌握”熟练度；不熟悉时显示可选备注，已掌握时隐藏备注；清单包含熟练度，仅不熟悉时导出该备注。切换选项不会直接抹除已输入备注。
7. 删除学习表单、搜索提示、检索及导出中的标签功能；旧标签数据暂存数据库，避免破坏兼容性。适用条件优先读取该同式主公式当前版本最新有效的已完成AI解释；没有结构化AI解释时留空。用户修改或清空后，之后读取会保留其自定义值。
8. 复习问题改为每组两行“问题：输入框”“答案：输入框”；首次自动生成3组带答案的个性化问答，结合已保存的年级与学习目的。点击右侧“添加问题”才新增空白手动问答，支持移除；每条公式最多20组。已保存问答不因重新打开页面而自动覆盖。

## 实现与兼容方式

- 使用增量迁移`202611090003_personalized_learning`：增加用户可选资料、学习问答JSON、熟练度与条件自定义标记，以及问答生成缓存表；没有重置现有账号、公式、历史或学习笔记。
- 旧的单个复习问题转为一组手动问题，旧条件保留为自定义值；保留旧`question`、`tags`字段及旧请求兼容，不再展示标签。
- 自动问答按账号、同式主公式、公式版本和年级／目的／提示版本的摘要缓存；并发请求复用同一处理记录，成功后复用结果，不重复扣额度。生成中离开页面不会取消服务器已经开始的处理，重开页面可取得缓存结果。
- 一次新生成3组问答使用1次AI额度；手动添加不使用AI额度。失败结果也保留，刷新不会自动再调用；用户显式点击“重试AI问答”才重新发起并使用新的1次额度。沿用现有AI请求额度规则，不把失败请求当作未发生。
- 生成调用在数据库事务外进行；账号级锁、唯一上下文键、处理期限及令牌避免重复领取和迟到响应覆盖新重试。输入、输出均校验，输出必须恰好三个不同问题且答案非空。
- 前端生成结果与用户已增加的手动问题合并，不覆盖等待期间输入的手动内容；保存和生成清单继续使用修订号保护。版本冲突时保留当前输入并提示核对。
- 资料和学习写入均携带预期账号标记；后台始终使用签名Cookie身份，外部账号不能读取、生成或写入其他账号的公式学习资料。
- 学习笔记接口正文单独放宽到256KB，以支持20组长中文问答；其他JSON接口保持原32KB默认上限，仍保留正文读取时间与大小限制。
- 复习卡片展示保存的全部问题，揭示答案后展示各组答案；Word学习清单包含用户所选资料、熟练度与问答，主公式保持原生可编辑的Word公式。

## 边界、风险及维护

- 年级与学习目的均可为空；未填时按该公式的基础理解层次提问。更改资料后不会擅自替换已保存的问答，用户可自行编辑。
- AI答案可编辑，单次实测不代表所有公式、学段和学习目的都已覆盖；没有重新评估识别模型准确率。
- 条件只复用当前版本有效的结构化AI解释，无法可靠解析的旧纯文本解释不自动抽取；用户可手动输入。
- 问答生成复用现有AI服务调用方式，缓存记录不是新增的Worker队列任务；服务重启导致未确认时，过期后提示显式重试，不进行隐式扣费重试。
- 问答、条件和熟练度按同式主公式共用；既有独立笔记仍沿用原关联规则，不自动合并旧数据。
- 数据结构保留兼容字段，没有新增第三方依赖。新增维护点是问答缓存与个人资料字段；旧兼容字段后续可在完成版本迁移后单独清理，当前未作破坏性删除。
- 完整浏览器与实际服务验收脚本仍位于`tmp`，尚未纳入隔离CI；永久组件和输入测试已补充。现有个人页统计的开发态SSR提示不在本轮改动范围。
