# R2 设计系统实施计划

基线：`8e8352c3cbb4a0962b90caf6ec5786b07469389b`。本轮沿用已确认的浅紫纸页语言，不执行迁移，不修改后端业务。

1. R2-A：检查原素材。现有完整设计板不能作为独立生产插画，采用仓库原创 SVG；修复三处资源引用，先执行资源检查及隔离生产构建、客户端校验。
2. R2-B：记录 CSS 最终生效值，合并重复声明；保留 480px 容器与既有基础尺寸。只建立一套 Token；用兼容别名保留现有使用点，新增状态、排版、交互语义。
3. 样板：使用现有 PageHeader/PageIntro、MathFormula、UserAvatar、EmptyState、AppModal、AppToast 和现有控件 class，不新建完整 UI 框架。样板只在显式加载的预览层出现，不增加生产页面。
4. 展示桌面居中 480px 与宽布局的对比；宽布局只在样板启用，等待用户选择。
5. 验证：真实浏览器移动/桌面截图、键盘焦点、弹窗、错误、加载、长公式与窄屏；类型、改动文件格式、单元测试、资源、生产构建、客户端扫描。历史 15 项格式问题不批量处理。
6. 完成后停止，不进入 R3，不自动将样板新风格应用到 17 页。最终视觉仍需用户确认。
