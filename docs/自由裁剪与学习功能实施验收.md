# 自由裁剪与学习功能实施验收

日期：2026-11-09

## 本次范围与使用入口

按本次确认实现建议中的1、2、4、5、6、7、8、9、10；没有新增建议3的历史版本恢复操作。

| 功能         | 入口与行为                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 自由裁剪     | 普通上传选择多公式后，在“自动裁剪公式区域”上方点击“手动裁剪公式区域”；可以在图片任意位置裁剪多个矩形区域，调整顺序或移除区域后再提交 |
| 批量裁剪     | 多公式批量中每张图片可手动裁剪；保留原有“一键检测”流程，已有手动区域不会被检测覆盖                                                   |
| 上下对照     | 公式详情显示原图在上、数学公式在下；批次结果逐条显示裁剪原图和对应结果，手机与桌面采用相同顺序                                       |
| 准备草稿     | 普通上传和批量准备自动保存图片、模式与区域；刷新后点击“继续上次准备”，恢复后由用户点击识别，不会自动提交                             |
| 回收站       | “我的→回收站”可恢复软删除的公式、识别记录、批次记录；公式按同式关联组恢复，收藏不自动恢复                                            |
| 任务中心     | 全局页面上方及“我的→任务中心”；查看识别、批次、AI回答、异步Word导出状态，进入相应详情继续处理                                        |
| 图片质量提示 | 普通上传和批量图片下方提示分辨率偏低、偏暗、可能模糊或倾斜；只作提示，不阻止识别，也不修改图片                                       |
| 学习资料     | 公式详情“我的学习笔记”填写适用条件、个人笔记、标签和复习问题，点击“保存学习资料”；公式库搜索可匹配笔记、条件和标签                   |
| 学习单       | 公式详情、公式库管理选择、批次结果勾选后点击“生成学习单”；可选择原图、条件、笔记标签和已有AI解释，下载可编辑公式的DOCX               |
| 复习卡片     | 详情学习资料勾选“加入复习卡片”并保存，“我的→公式复习”查看答案、自评；不会10分钟后、模糊1天后、会了首次3天后再逐次翻倍，最多90天      |

## 数据与兼容性

- 新增`formula_learning`表及`Formula.learning`关系；使用增量迁移`202611090002_formula_learning`，没有重置账号、公式、原图、版本或历史数据。
- 学习资料按当前账号及同式主公式读取；同式关联后使用主公式的学习资料，已有各条独立资料不会自动合并。复习列表按主公式去重。
- 笔记保存和复习评分使用修订号及账号级事务锁；过时请求返回409，避免多窗口覆盖或重复评分。
- 恢复识别历史只清除隐藏标记，不改变识别生命周期时间、任务状态或Worker租约；不会重新识别、增加收藏或重复消耗额度。
- 学习单使用已保存内容及已有解释，不重新调用AI；每次成功导出使用1次文档额度。通过受限Pandoc JSON结构生成原生Word公式，笔记作为文字处理。
- 复用当前裁剪组件、后台识别队列、账号鉴权、对象存储、文档工具和缓存失效方式，没有新增依赖或修改模型权重。

## 已知边界、未验证内容与后续维护

- 草稿只保存在同一浏览器、同一设备，按账号分开；浏览器清理站点数据后不能恢复，单份草稿上限200MB。自动保存尚未完成或存储失败时会提示；开始识别仍需用户提交。
- 自由区域为矩形，不要求上下排列；没有新增任意角度矫正或重训练布局检测模型。质量检测属于启发式提示，可能误报，不能替代用户检查。
- 没有重新评估模型在各类实拍图上的整体识别准确率，也未遍历不同浏览器的存储配额与系统级崩溃恢复。
- 回收站每种类型展示最近100条，无自动过期清理或永久删除入口；不能恢复已被物理删除的文件。独立聊天删除沿用原逻辑，不属于本次回收站。
- 任务中心每种类型合并最近30条与最多100条待处理任务，数量标记统计全部待处理任务；轮询可能有短暂延迟。即时生成的学习单直接下载，不会额外保存为异步导出任务。
- 一次学习单最多20条公式、输出最多8MB；大量图片需要减少数量。笔记显式点击保存，不会自动保存未提交的文字编辑。
- 复习每轮最多读取100张卡片；后续有大量数据时可加游标分页。新浏览器端到端验收脚本目前保留在`tmp`，尚未并入隔离环境CI，属于后续测试维护工作。
- 新增的主要维护负担是学习资料表与本机IndexedDB草稿；没有新增第三方依赖、绕过校验或改变既有Worker重试协议。
