# 环境变量

.env 是本机私有配置，.env.example 是模板；模板不替代实际凭据。Nuxt 私有 runtimeConfig 对应不带 PUBLIC 的 NUXT_ 变量，Worker 与脚本也读取所需变量。生产使用容器环境注入，不能假设构建后的 Nuxt 自动加载开发目录 .env。

修改配置后按影响重启 Nuxt、Worker 或对应容器。生成脚本只补齐缺少的值；更改 Docker 初始化变量不会改变已有数据库卷中的密码。

## 数据库与会话

| 变量                                            | 用途                                                              |
| ----------------------------------------------- | ----------------------------------------------------------------- |
| NUXT_DATABASE_URL                               | Prisma、API 和 Worker 的业务数据库连接                            |
| POSTGRES_USER / POSTGRES_PASSWORD / POSTGRES_DB | Compose 首次初始化数据库                                          |
| NUXT_AUTH_SECRET                                | 会话服务私有密钥，至少 32 字符                                    |
| NUXT_AUTH_BASE_URL                              | 网站实际根地址；本地为 http://127.0.0.1:3000，生产对应 HTTPS 域名 |

初始化使用 db:env 和 auth:env。会话密钥不是用户密码，轮换可能影响已有会话。数据库地址不要在公开诊断中完整输出。

## 注册邮箱

| 变量                  | 用途                                      |
| --------------------- | ----------------------------------------- |
| FORMULA_SMTP_USER     | 发件邮箱                                  |
| FORMULA_SMTP_PASSWORD | 邮箱服务授权凭据，QQ 邮箱使用 SMTP 授权码 |

当前注册邮件适配 QQ SMTP，使用 465 端口和 TLS。授权码不是邮箱登录密码，每个部署者单独准备并私下保存。注册验证码、发送频率和登录校验由认证实现管理，不能把真实验证码写进日志。

## Python 识别

| 变量                         | 用途                                                |
| ---------------------------- | --------------------------------------------------- |
| NUXT_RECOGNITION_PROVIDER    | mock 或 python                                      |
| NUXT_RECOGNITION_SERVICE_URL | 本地 http://127.0.0.1:8001；容器网络使用识别服务名  |
| NUXT_RECOGNITION_API_KEY     | Worker 与 Python 的共享服务密钥，至少 24 位、无空白 |
| RECOGNITION_MODEL_PATH       | 本地默认 ../model；只读挂载到容器                   |
| RECOGNITION_PORT             | 本地映射端口，默认 8001，内部为 8000                |
| RECOGNITION_CPU_THREADS      | 默认 4，仍为单路推理，不等于可并行处理四个任务      |

recognition:env 检查模型并补充配置，保留已有非空来源值。Compose 将识别密钥映射为 Python 内部 RECOGNITION_API_KEY，不用另设一套值。详见[模型手册](Docker模型服务操作手册.md)。

## AI 解释与追问

| 变量             | 用途                                                     |
| ---------------- | -------------------------------------------------------- |
| NUXT_AI_PROVIDER | mock 或 deepseek                                         |
| NUXT_AI_API_KEY  | 供应商私有 Key                                           |
| NUXT_AI_MODEL    | 使用账号有权限调用的模型；代码回退值不代表供应商始终提供 |
| NUXT_AI_BASE_URL | API 基础地址，默认 https://api.deepseek.com              |

启用 deepseek 不会在失败后自动伪装为 mock。详见[联调手册](DeepSeek配置与联调手册.md)。

## 私有存储

| 变量                                                        | 用途                                                   |
| ----------------------------------------------------------- | ------------------------------------------------------ |
| NUXT_STORAGE_ENDPOINT                                       | S3 兼容服务 API，本地 SeaweedFS 默认回环端口 8333      |
| NUXT_STORAGE_REGION                                         | 签名区域；本地兼容服务约定 us-east-1，不代表数据所在地 |
| NUXT_STORAGE_BUCKET                                         | 当前私有桶                                             |
| NUXT_STORAGE_ACCESS_KEY_ID / NUXT_STORAGE_SECRET_ACCESS_KEY | 成对使用的访问凭据                                     |

storage:env 补齐本机设置，storage:check 验证签名访问。生产容器地址与本机不同，不能照抄 localhost。详见[存储手册](私有对象存储操作手册.md)。

## 额度、转换与清理

| 变量                         | 默认与边界                                   |
| ---------------------------- | -------------------------------------------- |
| NUXT_RECOGNITION_DAILY_LIMIT | 每账号每天 50 次识别                         |
| NUXT_CHAT_DAILY_LIMIT        | 每账号每天 30 次对话                         |
| NUXT_EXPORT_DAILY_LIMIT      | 每账号每天 20 次导出                         |
| PANDOC_PATH                  | 可选 Pandoc 完整路径，否则按运行环境寻找工具 |
| FORMULA_RESOURCE_ORPHAN_MODE | off/report/apply，默认 report                |

日额度接受 1～10000 的整数，按 UTC 日期切换，不等于供应商 token 费用。任务自动重试不重复扣项目额度。apply 只执行通过条件的孤立图片回收，详见[失败恢复](FAILURE_RECOVERY.md)；不涉及模型和备份。Pandoc 便携工具不随 Git 分发，克隆后需安装或配置。

## 可选监控与邮件告警

观测启动脚本生成独立的本机凭据、采集和导出配置，入口、端口及安全约束见[观测指南](OBSERVABILITY.md)。常规开发不要求监控栈运行，也不要把全部采集端口开放到公网。

FORMULA_ALERT_EMAIL_ENABLED 默认 false；显式 true 才启用告警发信。FORMULA_ALERT_TO 指定接收者，未指定时按脚本规则使用发件邮箱。注册邮件与告警邮件独立：关闭告警邮件不影响注册验证码，不能靠关 SMTP 来停用告警。

完整配置入口以 [.env.example](../.env.example)、[Nuxt 配置](../nuxt.config.ts)、Compose 和相关启动脚本为准。不要新增未被程序读取的变量后误以为配置已生效。
