# 第7天实施计划

目标：当前账号能够查找、分类和收藏自己的公式；刷新后保留全部操作。

依据：[十五天开发计划](../十五天开发计划.md)第7天及用户确认的开发范围。采用 brainstorming、writing-plans 和 executing-plans 流程，在当前会话执行；本目录没有 Git 仓库。

## 实现约定

- 复用 PostgreSQL 中的 Formula、FormulaVersion、Category、Favorite，不新增数据库表，不引入模型依赖。
- `/account/library` 与 `/account/favorites` 使用同一列表组件；已登录访问 `/library`、`/favorites` 时跳转对应账号页面。访客仍可体验明确标识的本机演示。
- 普通文本搜索匹配标题和**最新版本**的 LaTeX，忽略大小写，最多200字符，百分号、下划线和反斜杠按字面含义匹配。
- 分类仅一层，每条公式最多属于一个分类；名称去首尾空格、Unicode NFC 规范化、1～50字符，同一用户不允许重名。
- 删除分类在事务中先解除公式分类再删除分类，保留公式、版本和收藏。界面先明确说明，再由用户确认删除。
- 收藏使用显式的目标布尔值，重复提交不生成重复记录；沿用无外圈的爱心按钮。
- 列表按创建时间、UUID 倒序，每页20条；游标必须归属本人。分类、搜索、收藏条件可以组合，切换条件从第一页开始。
- 身份只来自会话。所有读写附带 ownerId，写接口检查 Origin；他人资源统一404。列表只返回展示字段。
