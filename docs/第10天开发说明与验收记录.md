日期：2026-10-21。范围依据 [第10天实施计划](第10天实施计划.md)。本次完成前后端阶段验收、弱网修复和 Python 接入交接说明；**没有接入真实 Python 模型或大模型，手机检查使用浏览器视口模拟。**

## 具体改了什么

复现到的主要问题是：对话记录已经显示，但下一次读取失败时，Nuxt 默认把数据重置为空，导致历史消息和公式上下文突然消失。修改前的浏览器记录是“失败前2条消息，失败后0条”；恢复网络后数据库里的消息仍在，属于页面读取状态问题。

现在公共轮询保存最近一次成功快照。临时断连、503或超时会显示错误和重试入口，继续展示此前记录，并暂停发送提问和自动轮询。错误提示放在消息末尾，出现时自动滚动到可见位置，避免长对话把重试入口留在屏幕上方。**401、403、404会清除快照**，避免登录失效或资源无权访问后仍展示旧内容。再次读取成功后，更新真实数据并按任务状态决定是否继续轮询。

读取请求设置15秒超时，向 HTTP 请求转发 Nuxt 的取消信号；手动重试与轮询共用 `dedupe: 'defer'`，正在读取时合并重复操作。错误状态下按钮显示“正在读取…”，不会无限向不可用服务重试。离开组件时清理计时器，HTTP 生命周期由 Nuxt 及传入的信号管理。

创建对话、重新提交识别、重新提交导出和版本编辑补充20秒请求超时，防止弱网下提交按钮长期停留在处理中。原有上传、识别、提问和导出的请求键继续保留，写请求不自动重试；收到接受响应才进入结果/任务页或清空提问草稿。

没有新增数据库迁移、运行依赖或独立状态库。公共读取规则集中在一个组合函数中；任务页只负责状态和重试入口，对话组件只负责消息与输入交互。已有公式预览在长公式测试中表现正常，因此本次保留原组件，不为通过验收改写数学渲染。

## 浏览器验收结果

核心流程在最终生产构建上执行，使用独立 Playwright 会话和本轮临时账号。故障注入只作用于该浏览器的指定请求，没有关闭数据库或修改全局业务状态。

| 场景             | 方法与结果                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 临时读取失败     | 已显示12条消息时，对指定读取注入503；12条消息保留，输入禁用，自动轮询停止；恢复后得到完整16条消息（含随后完成的测试轮次） |
| 慢请求与连点     | 读取延迟2秒，同时点击重试3次，实际只发出1个读取请求                                                                       |
| 提问响应丢失     | 将真实 POST 成功响应丢弃；草稿保留，重试复用同一请求键；只出现一条对应用户消息，额度只增加1                               |
| 上传响应丢失     | 真实图片上传成功后丢弃响应，再重试；两次上传复用同一上传键，不重复保存图片                                                |
| 识别提交响应丢失 | 任务实际入队后丢弃响应，再重试；两次识别复用同一请求键，最终只增加1个任务和1条公式                                        |
| 导出响应丢失     | 真实导出提交后丢弃响应，重试复用请求键，只扣1次额度；任务完成后刷新仍能取得下载入口                                       |
| 读取超时         | 指定读取延迟17秒，页面约15.232秒结束等待；只有1次慢请求，旧消息保留；手动重试成功恢复                                     |
| 真实会话失效     | 在已打开对话中实际调用退出接口，再读取返回401；消息与上下文清空，输入禁用；刷新进入登录页并保留返回路径                   |
| 长公式           | 使用50项带上下标公式，在320/390/480/1280px下逐一滚到首尾；首项和末项均可见，页面无横向溢出                                |
| 矮屏与非法 LaTeX | 320×480编辑弹窗可滚动到保存按钮；输入不完整的 `\frac{` 显示明确预览错误，页面不崩溃；关闭弹窗不保存测试草稿               |
| 对话布局         | 四种宽度下无横向溢出；既有无输入外框、消息换行和底部输入栏样式保留                                                        |

脚本分别位于 `artifacts/day10-baseline.js`、`day10-network.js`、`day10-layout.js`、`day10-upload-recovery.js`、`day10-session-setup.js`、`day10-timeout-session.js`、`day10-error-visibility.js`。最后一项在长对话中实际测量重试按钮位于输入栏上方，无需脚本手动滚动。脚本包含本轮精确临时资源地址，**供查阅验收过程，不是可直接复跑的通用测试命令**；清理账号后需重新建立自己的夹具。

页面正常流程没有运行时异常。故障注入主动产生的503、网络失败，以及会话退出后的401为预期结果。开发/生产服务切换时原开发页曾产生资源重连日志，生产页面重新加载后执行验收，不将旧页面重连日志归为产品错误。
