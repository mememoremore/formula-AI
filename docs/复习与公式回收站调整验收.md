# 复习流程、公式回收站与推荐方案

日期：2026-11-09

## 本轮修改

- 复习卡片先展示公式原图和问题；无原图或加载失败时显示数学公式。点击“查看答案”后显示各题答案、适用条件、学习笔记及自评操作。
- 提示改为“回忆适用条件并回答以下问题，思考完再查看答案”；删除卡片下方“重新读取卡片”按钮。
- “包含尚未到期的卡片”保留：默认只读到期卡片，勾选后允许提前复习。
- 按本轮明确选择，回收站只保留公式，识别和批次记录均移除；展示公式实际内容、删除时间和到期时间。
- 操作栏仅“全选、恢复、清空”；清空前确认，清空后无法恢复，不会删除已有对话、导出及其历史引用。
- 新增独立公式回收记录，保留删除后的10天恢复窗口；重复删除不延长期限，恢复后再次删除才建立新窗口。
- 查询与恢复接口立即检查到期时间，不依赖清理进程；页面自动移除到期条目，服务启动及每分钟清理过期回收记录。
- 清理仅删除回收记录；保留历史引用需要的软删除公式、版本及原图，不做级联擦除。

## 个性化推荐备选方案

当前可使用年级、学习目的、分类、公式内容、适用条件、熟练度和复习排期；尚未建立每条公式的标准学段、难度及前置知识数据。

| 方案 | 实现方式 | 取舍 |
| --- | --- | --- |
| A 规则推荐 | 优先未掌握、到期公式，结合分类及人工设置的学段难度评分 | 快、透明、无额外AI调用；缺少公式知识信息时，年级目的匹配较粗 |
| B AI直接挑选 | 给AI用户资料及一批库内公式，选3～5条并说明理由 | 对自由文本目的匹配较灵活；需限制候选数量、验证库内ID并缓存 |
| C 规则初筛加AI排序 | 规则筛选约20个候选，再结合年级目的由AI选3～5条，给出学习顺序与理由 | 建议采用；兼顾可控、相关性和请求量，工作量高于A |

C的建议约束：只选择用户现有公式ID；同式去重；已掌握降低优先级；库少时少推荐，不凑数；资料、公式或熟练度变化后更新缓存。无需先增加向量数据库。候选生成、评分和重排的分层可参考 [Google推荐系统架构](https://developers.google.com/machine-learning/recommendation/overview/types)。
