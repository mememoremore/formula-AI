# 第10天实施计划

依据：[十五天开发计划](../十五天开发计划.md)及本轮“Day10可以先做”的授权。沿用已确认的前后端阶段验收范围，在当前会话逐项执行；所有说明使用中文文件名，代码保留现有职责边界。

## 目标与边界

验证登录、上传、异步任务、编辑、公式库、对话和导出的完整链路，重点检查弱网、长公式、重复提交及权限。只修复验收发现的问题，不新增模型实现，不调整已确认的每日额度、数据库设计或页面风格。识别和回答仍为固定模拟，真实模型效果不能由本次验收证明。

方案选择：沿用现有接口与组件，集中修复公共轮询并复用既有公式预览，比在每个页面分别写恢复逻辑更容易维护；本阶段不引入额外状态库或自动无限重试。弱网时显示明确提示和重试入口，写请求沿用原请求键；只在服务端确认接受后清空输入。

## 检查方式

浏览器通过 Playwright 路由对指定请求延迟、拒绝或在真实写入后丢弃响应；恢复时重新访问真实服务。记录重复请求键及提交后业务记录数，不以按钮禁用状态代替幂等验证。新改动后运行 `test:workspace`、`test:library`、`test:api`、`test:private-config`、`typecheck`、`build`、`format:check`。

Python 方案只形成交接文档：图片字节由 Node Worker 发送给私有推理服务，服务返回纯 LaTeX 和模型版本；保留当前 RecognitionAdapter 边界。协议是待朋友确认的建议，不写成已有可用服务。
