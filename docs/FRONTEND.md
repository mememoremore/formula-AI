# 前端页面与状态

## 页面职责

| 页面                                | 职责                                |
| ----------------------------------- | ----------------------------------- |
| /login                              | 账号登录、邮箱验证码注册            |
| /                                   | 账号首页与操作入口                  |
| /upload                             | 相册/文件与拍照、图片裁剪、识别提交 |
| /recognitions/:id、/result/:id      | 任务恢复与识别结果                  |
| /library                            | 搜索、分类、收藏、最近识别与分页    |
| /formulas/new、/formulas/:id        | 手动创建、编辑预览、解释与导出入口  |
| /ai、/ai/new、/ai/:id               | 会话列表、新建对话与流式问答        |
| /exports/:id                        | 导出进度和下载                      |
| /profile、/profile/edit             | 资料和账号统计                      |
| /settings、/help、/feedback、/about | 设置与说明页                        |

路由文件在 [app/pages](../app/pages)，业务逻辑放入 composables，复用展示放入组件，共享输入和数学规则在 shared。页面要求登录，旧演示存储和入口只作为兼容实现，不继续扩展双轨功能。

## 服务端状态与页面状态

[Query 插件](../app/plugins/account-query.ts)为每个 Nuxt 应用实例创建 QueryClient，服务端请求之间不共用全局缓存，使用 SSR dehydration/hydration 衔接首屏。账号范围的查询键包含已确认 owner；查询参数属于键的一部分。

远端公式、分类和详情由 TanStack Vue Query 管理读取状态。筛选条件、输入草稿、裁剪弹窗等仍是本地状态，不能把全部交互塞入 Query 缓存。查询和缓存规则集中在 [app/queries](../app/queries)。写操作经业务 mutation 处理，成功后统一失效相关列表、详情和统计，避免页面各自维护重复副本。

请求使用取消信号，搜索与分页防止过期响应覆盖新结果。账号切换、退出、会话异常时先阻断旧 owner 展示，再取消或清理缓存。前端 owner 保护与后端身份校验两者都需要。

## 写入回执与恢复

手动创建、识别和会话提交需要区分“请求没成功”和“结果没收到”。发出前保存 owner、requestKey 和原请求的受控回执；结果不确定时确认原操作，不换键自动重新创建。恢复回执原样校验，不再次 trim 或修改请求体。

Query 不自动重试有副作用的写入，也不实现离线提交队列。通用读刷新不能 POST 新任务。切回前台、恢复网络、页面刷新会对已知任务进行去重读取；原始未上传图像只在内存，关闭页面后不保证恢复。详见[失败恢复](FAILURE_RECOVERY.md)。

## 对话一致性

会话快照和活动轮次各有版本，SSE、停止响应、轮询共享新旧判断。只接收当前会话与当前 owner 的快照，旧请求不得把已停止轮次恢复为生成中。暂时读取失败保留最后一次成功快照，不直接清空内容。

提问排在对应回答上方。已接收的失败片段保留，重新生成使用新轮次和额度。历史完整问答与结构化解释按业务规则组成上下文，页面不展示供应商内部名称或 v1/v2 管理入口。

## 数学展示与移动布局

图片使用 Cropper.js 选择区域、缩放及旋转；首次选择取消裁剪恢复空态，重新裁剪取消保留已确认图片。图像校验和服务端 Sharp 解码仍必须保留。

LaTeX 通过 KaTeX 渲染，普通文本与公式片段使用统一的数学内容处理规则；无法渲染时展示安全文本并提示具体输入问题，不使用原始模型 HTML 注入页面。结构校验与渲染成功不等于数学结论正确。

移动端使用固定的对话头部和输入区、可滚动内容、安全区和溢出处理。布局变更至少检查 320/390/430 宽度及桌面，尤其是长公式、中文输入、空态、错误、滚动末尾和软键盘；桌面浏览器模拟不等于全部真机验证。
