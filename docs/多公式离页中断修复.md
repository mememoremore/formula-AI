# 多公式离页中断修复

日期：2026-11-08

上传页删除“公式名称（选填）”及输入框。新识别默认使用未命名公式，已有命名及详情页命名功能保留。

普通多公式识别原来由浏览器依次提交区域，并等待上一条完成。某条任务出现后即可点击进入详情，但离页会销毁区域组件、终止循环，因此后面的区域可能尚未上传或创建任务。已提交的后台任务继续运行，不能把未提交的区域计入已存在任务。

现在先上传原图及全部勾选区域，原子创建持久化批次后自动进入结果页；后台 Worker 根据该批次逐条识别。详情页返回保留完整批次，关闭页面也不影响剩余区域的提交。可从首页“批量处理”的历史批次重新打开结果。

## 边界与风险

上传尚未完成、批次尚未创建时仍需留在准备页；页面已有相应提示和离开确认。进入结果页后才保证后台继续，且本机数据库、存储、识别服务和 Worker 需要保持运行。

此修复没有自动重新提交用户以前未完成的区域，也未擅自重跑原来的六条图片。旧流程尚未保存的区域需要从原图重新勾选识别；已有成功结果不会因此删除。

本轮未做系统断电、后台进程重启故障注入，也未重复完整十张图片批次的浏览器验收。新增恢复逻辑有单元测试和六区域真实离页验收；未引入新的技术债务。
