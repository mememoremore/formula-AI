# 批次管理与图片格式统一

日期：2026-11-09

## 实现

学习记录空状态移除书本图标，其他页面的空状态图标保持原有默认行为。“最近批次”右侧新增与“管理公式”同样式的管理入口，支持勾选、全选、删除确认和重复删除保护。运行中和暂停批次必须先完成才能删除，避免隐藏后失去继续处理入口。

删除仅隐藏批次历史，不删除批次内部公式、原图、任务、请求编号或版本，也不改 Worker 状态、租约与调度时间。新增可空 `historyDeletedAt` 字段，迁移仅增加列；已应用19项迁移中的本次增量，无重置、数据清空或破坏性变更。旧批次默认仍可见，原请求重放仍可找到同一批次。

实际核对当前模型服务 `services/recognition/app/main.py` 的 MIME 限制、`engine.py` 的 Pillow 解码白名单，以及 Node 后端 `normalize-image.ts` 的文件签名与完整解码限制：当前支持静态 JPEG、PNG。JPG 和 JPEG 是同一类型的不同常用扩展名。统一显示为“JPG/JPEG、PNG”，每张最大10MB、2000万像素；没有扩展为模型未开放的 HEIC、WebP、GIF 或 PDF。帮助页同步更新已有的多公式和批量处理能力。
