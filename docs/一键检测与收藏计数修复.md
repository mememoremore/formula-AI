# 一键检测与收藏计数修复

日期：2026-11-08

## 修改结果

批量处理的多公式模式删除每张图片的“检测并调整区域”入口，改为“开始批量识别”上方的一键检测。一次点击按顺序检测所有图片，直接在各原图下展示全部区域。用户可以取消勾选、裁剪和手动补充区域；调整立即更新待识别列表，最后统一开始批量识别。

检测阶段不创建识别任务、不消耗模型识别额度。只有点击开始识别，全部图片与选中区域才会保存到持久化批次，再由后台按顺序调用模型。离开结果页不会终止后续区域的识别。

个别图片检测失败会继续检测其他图片。一键重试跳过已成功的图片，并保留手动调整。检测过程中禁用换图、排序和区域编辑，以免把结果关联到错误图片。单公式图片模式仍可逐图裁剪，无须区域检测。

收藏页原先列表已过滤收藏，但分类统计仍请求了全部公式计数，所以即使收藏为空，分类标签仍可能显示6。现在全部、未分类和每个分类都按收藏关系统计；保存页仍显示全部公式数量。两种统计有独立查询键，避免切换视图时误用缓存。收藏、取消收藏会刷新两种统计，未点击爱心不会因识别或保存而增加收藏。

## 边界与风险

每批仍最多10张，每张多公式图至少选择2个、最多20个区域，沿用原限制。准备与上传尚未完成时需要留在准备页；保存批次进入结果页后才由后台持续处理。单张检测只得到1个区域时，需要手动补充，或改用单公式模式。

本轮实际识别验收为2张图片、5条公式，未再做10张图片上限的长时压力测试及断电故障注入。收藏计数沿用同式关联的根公式统计规则和显式收藏写入逻辑，没有新增自动收藏行为。未引入新的技术债务。
