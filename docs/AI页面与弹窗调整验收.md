之后的弹窗检查跳过真实 API 调用，没有重复产生模型请求。临时验收账号及其测试公式、对话在完成后清理，用户现有账号和内容保留。

## 视觉与交互验证

- 手机尺寸 `390×844`：品牌和头像显示；欢迎语与输入框的浏览器计算字号均为 `16px`。
- 普通复制弹窗、Word 导出弹窗、sheet 编辑弹窗、contained 公式选择弹窗以及原 fullscreen 裁剪弹窗全部居中。
- 电脑尺寸 `1280×900`：复制与 sheet 编辑弹窗仍居中。
- 自动检查弹窗边界中心相对视口中心的误差小于2px，并确认弹窗没有超出视口。
- 图片裁剪仍保留必要操作空间和滚动；超长内容受最大高度约束。
- 浏览器验收无页面脚本错误。截图在 `artifacts/moxi-ai-center/`，包括品牌欢迎页、真实 AI 回复和居中的复制弹窗。
