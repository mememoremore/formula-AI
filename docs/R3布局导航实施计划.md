# R3 布局与导航实施计划

基线：`e15af3b`；工作分支：`refactor/r3-layout-navigation`。依据本轮已批准的混合式响应布局要求实施，保持默认 480px，不修改业务页面、服务端或接口。

## 设计与边界

- 默认 `compact` 保持 480px；`reading` 在 900px 起最大 760px；`workspace` 在 900px 起最大 1080px。小屏始终单列、宽度不超过视口。760px 是阅读行长上限，1080px 沿用 R2 桌面样板；900px 以下不提前拓宽已有页面。
- `definePageMeta({ contentWidth: 'reading' })` 为将来逐页采用的接口；17 个业务页面本轮保持原模式。
- 布局统一负责安全区、底部导航占位和公共浮层位置。导航保留 fixed、Teleport、四个入口及旧路由映射。
- 保留同一入口再次点击时的查询参数；跨入口只传递显式 demo/account 空间，不传播搜索词或公式版本。
- 同页参数变化继承原返回来源；浏览器前后退优先使用路由器提供的滚动位置。滚动快照在离开前记录，最多保存 100 项。
- 原生 dialog 继续负责顶层和焦点；公共 CSS 限制背景滚动，不新增全局滚动事件监听。

## 实施与验收顺序

1. 核对 R2 提交、工作区、现有页面元信息、路由及公共组件。当前未找到独立 R0 报告文件；采用会话中的 R0 要求、实际源码及《Formula重构.md》交叉核对。
2. 布局批次：增加布局样式、元信息类型，连接 default 布局及底部导航宽度；修正 Toast、输入区占位与弹窗背景滚动。仅修改直接依赖布局的公共组件。
3. 导航批次：扩展现有 navigation 纯函数与测试，修正同页来源；增加有界滚动快照及路由前置捕获，验证监听释放；保留旧映射。
4. 复用 R2 干净预览启动器，通过显式加载的测试层添加布局样板，不新增正式产品路由。样板使用真实布局、导航、弹窗、Toast、输入区与长公式。
5. 安全检查：资源、类型、单元、修改文件格式、生产构建及客户端私有配置扫描。浏览器覆盖 320/390/768/1024/1440、旧地址、深链接、刷新、前后退、筛选上下文、长页、弹窗及输入。
6. 保存截图和完整验收说明，检查 Diff/敏感配置/受保护目录；独立本地提交，不推送，不进入 R4。

## 风险与回退

本轮风险集中于全局 CSS 和浏览器滚动时序，必须以浏览器结果为准。测试使用无开发凭据的预览；不启动数据库、队列、Python 或付费模型。未能真机验证的安全区和软键盘行为明确记录。R2 提交保留，可通过经确认的反向提交回退 R3，不执行危险覆盖或清理。
