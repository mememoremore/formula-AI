# 新公式推荐与选填标签调整验收

日期：2026-11-09

## 最终行为

- 资料标签统一为“年级（选填）”“学习目的（选填）”，沿用原有可选填与保存逻辑。
- 为你推荐保留库内规则预览；主动点击AI生成时，支持连续推导、结构相似、含义相近、公式化简四类库外新公式，不强求每类都有。
- AI输出1～3条精简推荐，必须引用当前候选中的1～4条来源；新公式不能只是库内已有公式的空白变体。
- 卡片显示类型、排版后的新公式、推荐理由、适用条件；可展开查看来源公式和推导步骤／关联说明。连续推导至少两步。来源链接指向真实公式，不把生成的推荐编号当成已保存公式地址。
- 显示“AI生成 · 待核对”；程序校验结构、来源、排版和重复，未集成计算机代数系统，不能宣称数学正确性已被自动证明。
- 用户点击“添加到公式库”后才保存；复用现有手动公式创建接口及未分类默认规则。保存的是标题和LaTeX；推荐来源、步骤及条件仍属于推荐缓存，不自动写入个人学习笔记。
- 保存请求编号由当前推荐指纹与内容稳定生成，刷新同一缓存、保存响应未知后重试沿用同一编号，复用已有幂等保存机制；账号变化和组件销毁沿用原写入取消保护。
- 保留单卡片、换一个、缓存与原额度规则；换一个不调用AI。旧版推荐使用不同指纹，不作为新版结果复用。空库不生成；生成失败或无可靠新公式时回退规则预览。
