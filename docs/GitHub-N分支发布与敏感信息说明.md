# N分支发布与敏感信息说明

日期：2026-11-10

## 分支规则

- 目标仓库：mememoremore/formula-AI。
- 本轮仅向新分支N提交和推送，不向main推送，不执行强制推送或合并。
- 发布源码、数据库结构迁移、测试、配置模板及说明；不把本机部署状态复制到GitHub。
- 数据库迁移文件是代码，可以提交；数据库实际账号、业务数据和数据库备份不能提交。

## 不应上传的内容

| 类别 | 包含内容 | 本项目处理 |
| --- | --- | --- |
| AI及模型服务密钥 | DeepSeek API密钥、识别服务API密钥 | 真实值只放本机.env，不进入Git |
| 账号与会话凭据 | 会话签名密钥、Cookie、登录令牌、浏览器登录状态、GitHub令牌 | 忽略.env、浏览器会话及认证缓存 |
| 数据库和对象存储 | 数据库连接密码、存储访问密钥、私有桶凭据、数据卷和备份 | 忽略数据目录和备份文件 |
| 邮件凭据 | SMTP授权码、发信账号的私有配置 | 本机配置不提交，不把邮箱授权码当普通示例 |
| 私钥与证书 | SSH私钥、云服务凭据、签名私钥和证书容器 | 忽略.aws、.ssh及pem/key/pfx等文件 |
| 用户业务内容 | 上传的原图、头像、公式笔记、聊天记录、导出Word和数据库快照 | 不发布运行存储、上传及导出目录 |
| 本机过程材料 | 日志、HAR网络记录、崩溃转储、临时验收账号与截图 | 忽略tmp、artifacts、日志与会话证据 |
| 权重及安装文件 | 模型权重、Docker运行数据、安装包、压缩包 | 忽略常见权重扩展名和安装包；使用者自行准备 |
| 构建与依赖 | node_modules、Nuxt构建结果、生成客户端 | 忽略生成目录，保留锁文件与生成说明 |

可提交.env.example，但敏感字段必须是空值或明确的示例占位，不可复制真实.env。代码中的配置变量名、环境读取逻辑及GitHub Actions的secrets引用可以保留。

模型权重不随源码发布；自行分发前还需核对模型及素材的许可。公开源码不等于公开数据库或生产服务。

## 本轮检查方法

- 核对Git远程、当前分支和待上传文件。
- 对待上传源码及当前HEAD可达历史Blob做检查；仅输出命中文件和规则名称，不输出密钥原文。
- 通过本机.env中敏感配置的实际值匹配，结合常见AI／GitHub／AWS令牌与私钥标记检查。
- 检查被Git跟踪的文件是否落在敏感路径、是否含大型文件；.gitignore不能自动排除已跟踪内容，因此同时检查历史。
- .env、模型、数据及本机日志保留在电脑中，不因本次忽略规则被删除。
- 这类扫描用于降低泄露风险，不能证明所有未知格式秘密都已被发现。若日后发现真实凭据进入远程历史，先撤销／轮换，再清理历史，不能只删除最新版本。
