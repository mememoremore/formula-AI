## 代码组织与数据流

- Nuxt 4 `app/pages/` 按路由分文件；`layouts/default.vue` 负责整体页面及共享导航。
- `components/` 提供导航、标题、公式渲染、公式卡片、空状态、弹窗等单一职责组件。
- `assets/css/` 集中定义设计变量、布局和通用控件；页面样式放各自的 scoped 样式中。
- `shared/types/` 定义前后端协议；服务端模拟适配器与 API 路由分离。
- 页面通过同源 `/api` 请求健康状态、示例公式、模拟识别与模拟对话。
- 本机演示数据可存 localStorage；页面明确说明数据仅保存在当前浏览器。无伪造登录或真实存储承诺。
- 上传首日只做浏览器选择及预览，识别使用固定样例；明确图片不会被真实识别。
- 密钥仅放 `runtimeConfig` 私有字段；`public` 仅包含应用名称等非敏感字段。
