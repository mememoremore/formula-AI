# Formula AI 首日与前端页面实现计划

使用 writing-plans 技能组织工作，在当前会话逐项执行。

**目标：** 创建可运行的 Nuxt + TypeScript 工程，按照 Figma 提前编写可维护的前端页面，打通首日业务 API。

**架构：** Nuxt 同时提供 H5 和 Nitro API。页面、共享组件、浏览器演示状态、服务端模拟适配器与共享接口类型各自独立。

**依据：** `docs/前端设计说明.md`、原始 `十五天开发计划.md` 及用户本次授权。

## 全局约束

- 使用 Nuxt + TypeScript，底部导航单独成组件。
- 按设计稿补齐缺失页面，保持手机优先及中文文案。
- 识别和 AI 固定返回示例，并显式标注；不宣称真实鉴权、云端保存及 Word 导出已完成。
- 私有配置不进入浏览器，数据库不阻塞首日启动。
