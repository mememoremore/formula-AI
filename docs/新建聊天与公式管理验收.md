# 新建聊天、管理公式与详情布局验收

日期：2026-11-08。项目：D:\墨析\formula-AI。

## 完成内容

1. AI 助手右上角“学习记录”左侧增加同类方框编辑图标与“新建聊天”按钮。已有对话也提供明确入口。移除上拉事件、上拉提示和对应样式。
   - 新建聊天从空草稿开始，首次发送才创建会话，不生成空白历史。
   - 未发送草稿仍可取消放弃；待确认请求保持原有恢复保护。
2. 公式列表已显示数量左侧增加编辑图标和“管理公式”。支持勾选、取消、确认后批量删除。
   - 删除同一公式时，保存列表、分类列表、收藏同步移除，收藏关系也在同一事务删除。
   - 原有不可变公式版本、对话和已导出文档保留；识别任务记录保留，并显示其公式结果已删除。
   - 每批最多100条，全部校验归属，混入其他账号公式时整批拒绝，重复请求幂等。
3. 两种批量选择统一使用简洁的选择条，只显示已选数量和一个带垃圾桶图标的“删除”按钮，删除清空和全选当前列表按钮。
   - 删除识别记录仍只移除记录在历史与首页的可见性，公式和收藏不随之删除。
4. 通过共用页面标题字号变量限制较大的内容字体。带返回标题的页面以21px为上限，公式库和 AI 主页面保留24px标题；首页、个人页沿用各自当前标题大小。相关组件、弹窗继承相同上限；较小文字保持原大小。
   - 数学公式基准字号不超过页面标题，分式、上下标和伸缩符号继续由 KaTeX 保持数学排版比例。
5. 公式库“已保存”更名为“保存”。
6. 详情页移除分类行，收藏爱心放在公式名称右侧。最底部增加全宽“添加到公式库”，点击打开居中分类弹窗，可选择已有分类或未分类。
   - 新公式未操作时默认未分类；取消弹窗不改变分类，已选择分类的旧公式不被自动重置。
   - 账号公式与本机演示详情采用一致布局；演示分类仍只保存在浏览器。
