# 墨析改版验收与文件清单

## 已实现

1. 可见品牌、网页标题、帮助和邮件等由 Formula AI 统一为墨析；基础设施项目标识 formula-ai 保留，以保持现有数据卷和服务兼容。
2. DeepSeek 私有配置保留在项目根目录 .env；NUXT_AI_PROVIDER 已设为 deepseek，只需填写 NUXT_AI_API_KEY。模型为 deepseek-flash，地址 https://api.deepseek.com。填写后重启网页及 Worker。
3. AI 入口改为直接聊天、按昵称欢迎、底部输入、学习记录、上拉或点击新聊天；继续复用原有幂等发送、流式回答和恢复。
4. 单/多公式切换；多公式先检测上下分开的区域，勾选并逐区域裁剪，再按顺序调用真实模型。原小程序及其后端没有修改。
5. 新生成的 Word 正文只放公式，不含标题、模拟说明或 LaTeX 源码。
6. 复制先选公式，再选择 LaTeX 或数学文本。Word 导出先选公式，再选可编辑/图片格式，然后新建或追加；追加不覆盖原文件。
7. 删除识别页截图中的相册/拍照重复按钮；两个入口共用页面，因此均生效。图片区域本身仍可上传或拍照。

## 尚未验证、限制与维护事项

- 用户未提供 DeepSeek 密钥，未执行真实付费模型调用。空密钥时界面明确不可发送，不会伪装为真实回答。
- 未在桌面 Word/WPS 中手工验收；已检查原生 OMML、DOCX XML、图片关系完整性并实际下载。
- 多公式为浅色纸张上上下排列公式的几何检测，不保证复杂页面、并排多栏自动分组；保留手动裁剪及独立失败重试。
- 复用当前数据库而不迁移结构：每条识别公式独立保存，批次页面按任务ID组织；单条任务与旧接口兼容。
- 追加文档上限5MB、一次最多20条公式；保留原文档原有内容，只对新增内容执行纯公式要求。
- 为保持小程序行为复用 MathJax 3.2.2（上游已推荐4系）；这是兼容性依赖，后续升级需重新核对公式文本和排版，不能直接替换。
- 新批量/追加导出为有边界的同步接口（每账号一份、全局两份并发），未改旧异步导出契约；大规模导出以后可以统一进入异步队列。这是当前实现的维护折衷。
- 未更改数据库结构、原小程序、账号密码、历史数据或模型权重。
