## 完整解释复制

只读取已经校验的 baseExplanation.structured，顺序固定为：

1. 概述。
2. 符号含义：$LaTeX$：含义。
3. 适用条件：编号列表。
4. 理解与推导：编号、标题、正文、可选 $$LaTeX$$。
5. 应用例子：编号列表。
6. 注意事项：编号列表。

没有条目的区块不产生标题。只复制用户可见内容，不加入任务、会话、消息 ID 或 Prompt 版本。它是普通文本，不是 Word 原生可编辑公式。

剪贴板写入成功显示 Toast；拒绝或缺少 Clipboard API 时显示明确提示、只读可选择文本和「选择全部内容」。内容变化或组件卸载后忽略旧回调；不会将解释写入全局缓存。普通账号 AI 回复和公式 LaTeX 使用同一组件，不增加新的 API。

## Word 指引

实际文案：支持 LaTeX 输入的 Windows Word 中，可按 Alt+= 插入公式，选择兼容的 LaTeX 输入模式后粘贴源码，再转换为专业格式。Word/WPS 对 LaTeX 的支持因版本而异，并非所有命令都能转换。复制完整解释得到的是普通文本；复杂公式优先下载现有的可编辑 DOCX。

依据：[Microsoft Word 线性公式与 LaTeX 说明](https://support.microsoft.com/en-us/word/linear-format-equations-using-unicodemath-and-latex-in-word)。没有实现 PNG、剪贴板图片或修改已有 DOCX。
