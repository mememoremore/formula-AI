## 找业务行为看这里

- 公式库：`AccountLibrary.vue` + `useAccountLibrary.ts`；包含等待与失败任务的最近识别为 `AccountHistory.vue`，演示为 `DemoLibrary.vue`。
- AI：`AccountConversations.vue` 展示会话；`AccountChat.vue` 展示正文；`useAccountChat.ts` 处理提问/停止，`useConversationEvents.ts` 处理 SSE，断线后交回 `useTaskPolling.ts`。
- AI 阅读：`ChatComposer.vue` 统一多行输入与停止按钮；`ChatMessageContent.vue` 识别数学分隔符，`ChatText.vue` 安全展示标题、粗体与代码；`useChatReading.ts` 只在底部跟随输出。
- 头像：`AvatarCropper.vue` 管选择后的拖动/缩放；`shared/avatar-crop.ts` 管裁剪几何。资料页保留草稿，保存成功后刷新会话。
- 上传：`useImageSelection.ts`、`useUploadPreview.ts` 管选择与预览，`useAccountRecognition.ts` 管账号上传及任务提交。
- 演示：`useDemoStore.ts`、`useDemoLibrary.ts`、`useDemoChat.ts` 和 `plugins/demo-storage.client.ts` 管浏览器数据；它们不调用账号写接口。
- 会话：`useAccountSession.ts` 读取真实身份，`useWorkspace.ts` 明确账号/演示语境。API 是最终鉴权边界，页面状态不能代替服务器权限检查。

页面 API 仍为 `/api/account/...`，不要随着页面路径迁移误改服务器接口。

## 路由与返回规则

`shared/navigation.ts` 集中定义主入口、页面归属、安全回跳和旧地址映射。`00.legacy.global.ts` 一次性替换旧链接，`01.navigation.global.ts` 记录可信站内来源，`usePageReturn.ts` 选择返回方式，`app/router.options.ts` 恢复滚动。

- `/account` → `/profile?space=account`。
- 旧账号库/收藏/历史 → `/library` 对应筛选，并保留账号语境。
- 旧任务、详情、导出、会话 → 当前规范 URL；旧页面文件通过 alias 兼容，不复制业务代码。
- 列表筛选、任务完成、首次发送后的会话 ID 使用替换导航，避免返回临时页。
- 有站内来源时返回来源；直接打开页面才使用公式库、AI 等兜底。不能统一改成固定链接或无条件 `router.back()`。
- 登录保留完整站内目标，拒绝外站地址和认证自循环；服务故障保留位置并允许重试。
- `space=demo` 明确查看本机演示；`space=account` 必须登录。演示数据不会自动迁移到账号。

## 新增资料接口

`PATCH /api/account/profile` 接收 `name` 及可选 `avatar`：省略头像表示保留，`null` 表示恢复默认，字符串为裁剪后的 JPEG/PNG data URL。`GET /api/account/avatar` 只返回当前登录者的头像。

校验在 `server/services/profile-input.ts`，图片处理在 `server/images/avatar.ts`，持久化在 `server/services/profile.ts`。头像重新编码为 512×512 WebP，私有对象键保存在已有 `User.image`，不新增数据库迁移。
