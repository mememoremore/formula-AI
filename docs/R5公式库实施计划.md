1. 已核对页面、账号/游客/历史、搜索、分类管理/归类、收藏、分页及 API。已保存六种视口修改前截图。仓库没有独立 R0 文件，结合《Formula重构.md》与 R2—R4 记录核对。

7. 加入纯规则单元与仅预览层的有状态 API 替身，测试分页、快速切换、失败重试、收藏/分类、后页任务状态、身份隔离和导航。明确 Mock 不代表真实后端联调。
8. 类型、资源、修改文件格式、单元、构建、客户端扫描、真实截图及范围审查后独立本地提交。
