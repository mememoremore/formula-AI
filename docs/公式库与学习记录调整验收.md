# 公式库、首页最近识别与 AI 学习记录验收

日期：2026-11-08。项目：D:\墨析\formula-AI。

## 本次行为

- AI 学习记录对照本机小程序实现：按名称实时搜索、清空搜索、自由/公式问答卡片、最近活动时间、修改名称、左滑删除和确认删除；无记录时显示“快来和墨析一起学习吧~ / 开始学习”。去掉原来的大号新对话按钮和日期分组。桌面端提供删除按钮，键盘可以操作。
- 公式库默认“最近保存”仅查询当前账号已加入分类且未删除的公式，最多10条，无继续分页；加入、移出或删除分类后刷新相关列表。“未分类”和具体分类仍可单独浏览，收藏逻辑保留。
- 首页改为“最近识别”，只请求识别历史，最多10条；点击打开识别结果或任务，全部记录指向识别历史。手动公式、最近对话不再混入；演示空间仍明确保留演示提示。
- 公式库、AI 入口和已有 AI 对话移除顶部品牌及个人头像栏。首页品牌及对话消息头像保留。
- 账号、原有公式、会话、识别数据均保留；未修改原小程序、数据库结构、密钥或 Docker 存储。

## 实现与兼容性

默认公式库客户端增加 saved=true 参数，数据库在查询时筛选 categoryId IS NOT NULL 并限制10条。旧的无参数接口继续返回原来的完整分页结果，避免破坏导出选公式等既有调用。查询缓存包含 saved 参数，防止两个列表混用缓存。

学习记录使用新 GET /api/account/conversations/history 接口，以名称检索、更新时间排序；原 GET /api/account/conversations 的标题/提问搜索和创建时间分页保持不变。改名和删除接口均校验账号归属与请求来源。删除与提交提问共用会话锁，存在排队或生成中任务时返回409，要求先停止；确认后只删除本人选择的会话及关联消息/任务，不删除公式。
