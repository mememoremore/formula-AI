# 三大主页面 · 第一步

以用户确认的三联设计稿为准，本轮仅验收首页、公式库、我的，以及这三个页面共用的底部导航。其他页面保留现状，后续分步调整。

## 实施与验收

- [ ] 共享底栏固定在视口底部，四入口选中状态准确；正文预留导航及安全区高度。
- [ ] 首页：品牌与头像、纸页插画、双按钮、简洁的继续对话和最近公式卡片。
- [ ] 公式库：三角纸页插画、搜索、三种视图、分类筛选弹层、原图缩略图与裸爱心卡片。
- [ ] 我的：默认插画头像、纸页与线条装饰、资料入口、四项菜单。
- [ ] 浏览器检查滚动、导航、筛选、搜索和收藏，并保存三页实际截图。
- [ ] TypeScript 检查、相关回归与生产构建通过。

## 代码边界

页面负责数据与入口；共享组件负责展示，继续复用现有 API、鉴权和收藏逻辑。登录用户只展示真实账号记录；游客预置内容明确标识为本机演示，不伪造对话历史。插画为本地静态素材，装饰不拦截点击。导航使用 Nuxt 的 SSR Teleport 容器，避免受页面祖先定位影响。

## 插画来源

使用内置 imagegen 生成并保存于 `public/images/`。提示词：温暖米白点阵纸页、淡紫胶带、紫色铅笔与抛物线；公式库使用标记 a/b/c 的三角纸页；默认头像使用黑色短发、淡紫上衣的柔和插画。均为透明背景，不把页面文字烘焙进图片。
