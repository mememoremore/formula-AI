# 墨析网页配置

DeepSeek 的接入已使用服务端适配器，不需要把密钥写进网页代码。

在项目根目录的本机 `.env` 文件填写：

```dotenv
NUXT_AI_PROVIDER=deepseek
NUXT_AI_API_KEY=在这里填写你的DeepSeek密钥
NUXT_AI_MODEL=deepseek-flash
NUXT_AI_BASE_URL=https://api.deepseek.com
```

`.env` 已被 Git 忽略。填写后重启网页和 Worker：分别运行 `npm.cmd run dev`、`npm.cmd run worker`。未填写密钥时，页面会明确提示 AI 服务未就绪，不会伪装成真实回答。

AI 入口直接显示聊天输入框；学习记录保留历史对话。已有聊天底部上拉可以开启新对话，也可以点击“新聊天”。

单公式保留自由裁剪和旋转。多公式先检测上下分开的区域，勾选后可以对每个区域手动裁剪；自动分割使用原小程序的几何分组和相邻墨迹清理算法。每个所选区域按顺序调用既有识别任务，成功公式独立保存在账号中。部分区域失败可以进入相应任务重试，其他区域结果保留。

复制时可选择 LaTeX 或数学公式文本；多公式先勾选再复制。公式文本使用 Unicode 数学符号，纯文本剪贴板无法保留堆叠分式，用括号明确层次，与小程序一致。

导出时先选择公式，再选择图片版或原生可编辑公式版，最后新建文档或追加到已有 DOCX。新增正文只包含公式；追加时保留原文并下载为新文件，不覆盖原文件。现有 Word 文档大小上限5MB，最多一次20条公式。旧导出接口继续可用，重新生成的文档也仅含公式。

识别模型、数据库、私有图片存储仍使用已有 Docker 服务。原小程序源码未改动；现有账号、历史和存储卷无需迁移。
